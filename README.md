# OhMyFood

## Description

This project was developed as part of the OpenClassrooms Web Developer program, focusing on advanced CSS techniques and SASS preprocessing.
OhMyFood is a responsive website showcasing restaurant menus with modern CSS implementations.

## Project Goals

-   Implement advanced CSS features and animations
-   Structure and optimize code using SASS preprocessing
-   Create a mobile-first responsive design
-   Follow Figma mockup specifications

## Technical Features

-   Modern CSS:
    -   Dynamic transitions and keyframe animations
    -   Gradient animations using @property
    -   Filter and drop-shadow effects
    -   Clamp calculations
-   SASS Architecture:
    -   7-1 pattern organization
    -   Mixins, functions, placeholders
    -   Variables, maps, loops, conditions
